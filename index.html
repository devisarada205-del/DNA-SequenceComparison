Four ways to compute the same answer

All four approaches use the same recurrence. They differ in how often they re-solve the same subproblem and how much memory they keep. Counts are measured live on your sequences.

04

Run the Python engine with Biopython

The same algorithms are written in Python (lcs_core.py) and run in your browser on a Pyodide Python runtime. Biopython adds a scored global alignment (Bio.Align.PairwiseAligner) for comparison with the LCS result. The repository also includes a Streamlit app built on the same module.

First run downloads the Python runtime (~10 MB). After that, runs are instant.
05

How the dynamic program works

1 · Subsequence, not substring

A subsequence keeps the order of the bases but can skip some. GTA is a subsequence of GATTACA. In biology this models conserved bases that survive insertions and deletions.

2 · Optimal substructure

Look at the last bases of the two prefixes. If they match, they can end the LCS, so the answer is the LCS of both shorter prefixes plus one. If they don't match, at least one of them is not in the LCS, so drop either one and keep the better result.

3 · Overlapping subproblems

Plain recursion reaches the same pair (i, j) through many different branches, and the work grows exponentially. There are only (m+1)(n+1) distinct pairs, so storing each result once brings the cost down to O(m·n).

4 · Reconstruct from stored states

The table holds lengths, not strings. To recover the subsequence, start at dp[m][n] and follow the decision that produced each value: diagonal on a match (emit that base), otherwise up or left toward the larger neighbour, until you reach a zero edge.

5 · Similarity measures

LCS similarity = 2·L / (m + n). Coverage = L divided by each sequence's length. Edit distance is a second DP (Levenshtein) that counts insertions, deletions and substitutions. Hamming counts mismatched positions when the lengths are equal.

6 · LCS vs. scored alignment

LCS rewards matches only. Biopython's global aligner (Needleman–Wunsch style) also scores mismatches and gaps, and it fills its own DP matrix with the same grid-and-traceback idea.
